# 옛 섹션 도움말 가이드 (fixture)

이 vault에는 생성 마커가 없어 `index.md`가 `## 가이드 / 레시피` 섹션을 수기로 유지한다.
그 행의 첫 컬럼은 wikilink이고 표시 이름은 alias에 있다 — 한글 전용이면 영문 grep이 못 잡으므로
§7-16이 WARN을 내야 한다.
