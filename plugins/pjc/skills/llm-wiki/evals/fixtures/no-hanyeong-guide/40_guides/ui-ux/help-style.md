# 도움말 스타일 안내 (fixture)

ui-ux 가이드는 기능별 인덱스에 등록되지 않아 '가이드 / 레시피' 섹션 alias가 유일 검색 경로다 —
alias가 한글 전용이면 영문 grep이 못 잡으므로 §7-27이 WARN을 내야 한다.
