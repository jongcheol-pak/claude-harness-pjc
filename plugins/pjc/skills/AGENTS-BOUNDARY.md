# AGENTS.md 내용 경계 (정본)

> 이 파일은 스킬이 아니라 **스킬 공용 참조 문서**다(frontmatter 없음 — 로더는 `<name>/SKILL.md`만 스킬로 등록한다).
>
> **이 파일이 「AGENTS.md 내용 경계」의 정본이다.** `docs/harness-conventions.md`에서 옮겨 왔다 —
> 그 문서는 **하니스 레포에만 있어** 다른 프로젝트 세션에서 포인터를 따라가도 열리지 않았다.
> 플러그인과 함께 배포되는 이 자리로 옮겨 어느 레포에서든 도달하게 한다.
> `bootstrap-agents-md`·`record-project-fact`·`llm-wiki`·`plan-feature`는 이 파일을 가리키기만 하고
> 각자 재서술하지 않는다.

> `docs/harness-conventions.md`의 「문서 로드 예산 기준선」이 **얼마나 큰지**를 재고 같은 문서의 「AGENTS.md 주입 상한 관리」가 **넘쳤을 때**를 다룬다면, 이 문서는 **애초에 무엇이 들어가는가**를 정한다. 셋은 계측 → 경계 → 처방의 한 벌이며, 경계가 없으면 나머지 둘은 매번 같은 자리로 돌아온다(실측: `AGENTS.md`가 `2026-08-05 16,249B → 08-06 13,965B → 08-20 16,348B → 08-21 14,783B → 08-22 13,192B` — 하루 평균 +170B로 자라 2주에 이관 3회).

**판정 기준은 하나다 — `AGENTS.md`는 매 세션 자동 주입되고 위키는 필요할 때 읽는다.** 그래서 *"매 세션 예외 없이 필요한가 · 틀리면 즉시 사고나는가"* 가 갈림선이다.

| 저장처 | 담는 것 | 근거 |
|---|---|---|
| **`AGENTS.md`** | 위키 포인터 1줄 · `## Build & Test`(빌드/실행/테스트 **명령** + ⚠ 1줄) · **검증 매핑 표** · `## Conventions`(인코딩·줄바꿈·주석 언어 + **아키텍처 선언 1줄** — "어디에 코드를 둘지") · `## DO NOT` · `## Plan Location`(경로만) · `## 데이터 접근`(명령·환경변수 **이름**만) · `## 산출물·파일 관리`(산출물·캐시 **경로**만) | 검증 단계마다 실행하거나, 파일을 쓸 때마다 적용되거나, 어기면 되돌리기 어렵다. **검증 매핑 표는 `AGENTS.md`에 있어야 게이트가 켜진다** — `implement-task` V-2가 그 표의 존재를 조건으로 쓰므로 옮기면 문서 이동이 아니라 동작 변경이다 |
| **레포 상세 문서**(이 레포는 `docs/harness-conventions.md`) | 각 검증 명령이 **무엇을 대조하는가** · **함정** · 축의 설명 | 명령을 실행할 때가 아니라 결과를 해석할 때 필요하다 |
| **위키**(`llm-wiki`) | 프로젝트 성격·`tech_stack`·플랫폼·레포 경로·**아키텍처 상세와 온보딩**(레이어·핵심 흐름·복잡도 핫스팟) · 기능 목록 · 크로스 세션 작업 규약·함정 · 결정 이력 · 기능 상세 | 그 작업을 할 때만 필요하고 계속 누적되며 코드를 읽으면 복구된다. 손으로 유지하는 사본이 낡는 대표 자리다 |
| **어디에도 안 감** | plan 진행 상태 · "다음 작업"·"다음 회차가 알아야 할 것" · 세션 인계 서술 | 진행 중은 `plan.md`, 영구 기록은 git 커밋 본문이 정본이다 |

**증가 억제 규칙.** `## Build & Test`에는 **명령과 ⚠ 경고 1줄만** 둔다 — *"그 명령이 무엇을 대조하는가"*·*"어떤 함정이 있는가"* 의 상세는 **레포 상세 문서**(이 레포는 `docs/harness-conventions.md`)로 보내고 포인터만 남긴다. 검증 축이 늘 때마다 이 절이 함께 자라는 것이 위 증가율의 정체다.

**서술 밀도 규칙.** `AGENTS.md`의 독자는 사용자가 아니라 **다음 세션의 에이전트 자신**이다. 설득·경위·근거 서술을 쓰지 않고 **명령·값·규칙·⚠ 1줄**만 적는다. *"왜 그런가"* 가 필요하면 **레포 상세 문서**나 위키로 보내고 포인터를 남긴다.

**이 표는 이 파일이 정본이다** — `bootstrap-agents-md`·`record-project-fact`·`llm-wiki`·`plan-feature`는 여기를 가리키기만 하고 각자 재서술하지 않는다.
