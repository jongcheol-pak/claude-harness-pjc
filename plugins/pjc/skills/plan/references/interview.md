# 인터뷰

> `plan/SKILL.md`의 「Step 2. 요구 인터뷰 (1문1답)」에서 분리됐다. 그 절이 발동 조건을, 이 파일이 절차를 담는다.

## 인터뷰 절차

### 2-1. 가설과 신뢰도부터 밝힌다

- **질문을 낼 때마다 다시 적는다** — 2-5의 정지 판정이 라운드별 신뢰도의 변화를 입력으로 쓰므로, 처음 한 번만 적으면 그 판정이 설 자리가 없다.

```
현재 이해: <한 문장>
신뢰도: <0-100>%
부족한 부분: <70% 미만일 때만 — 무엇을 모르는지>
```

### 2-2. 한 번에 한 질문, 추측을 붙여서

```
Q: <초점이 하나인 질문>
GUESS: <내 가설과 그렇게 생각하는 근거>
```

- **`GUESS:`를 반드시 붙인다** — 사용자가 "그건 아니고"라고만 답해도 진전이 생기고, 맞으면 "응"으로 끝난다. 추측 없는 질문은 사용자에게 설계를 통째로 떠넘긴다.
- **답을 받은 뒤에 다음 질문을 만든다** — 앞 답이 뒤 질문을 바꾸므로 미리 목록을 짜 두면 죽은 질문을 묻게 된다.
- **`GUESS:`를 맞을 것 같은 쪽으로만 내지 않는다 — 인터뷰마다 최소 한 번은 사용자가 반박할 것 같은 쪽으로 낸다** — 맞을 것 같은 추측만 내면 사용자는 동의만 하게 되고, 그 동의는 확인이 아니라 통과다.

### 2-3. 근거로 결정되는 것은 묻지 않는다

- **코드·`AGENTS.md`·위키·기존 컨벤션으로 답이 정해지는 항목은 자체 확정한다** — 명명 규칙, 기존 패턴 준수, 디렉터리 위치 같은 것을 물으면 사용자는 "알아서 해"라고 답하게 되고 질문 예산만 소모된다. 확정한 것은 plan의 Decisions에 `Source: <확인한 파일:라인>`과 함께 적는다.
- **단 `AGENTS.md`에 아키텍처 선언이 없으면 그것은 자체 확정 대상이 아니다** — 코드 구조를 보면 「지금 어떻게 돼 있는가」는 알 수 있지만 **그것이 의도였는지 누락이었는지는 코드에 없다.** 말없이 기본값을 적용하면 그 구분이 영영 생기지 않는다(`../SKILL.md` Step 1).
- **묻는 것은 근거만으로 결정할 수 없는 갈림길뿐이다** — 제품 방향, UX 선택, 비가역 데이터 형식, 범위의 크기.

### 2-4. "해야 할 것"과 "실제 원하는 것"을 가른다

사용자가 표준 용어("확장성", "깔끔한 구조", "베스트 프랙티스")로 답하면 한 번 더 묻는다:

> "정당화할 필요가 없다면, 실제로는 무엇을 원하시나요?"

- **이 질문이 필요한 이유** — 표준 용어는 무엇을 만들지 결정해 주지 않는데도 답변으로는 완결돼 보여, 그대로 받으면 계획이 추상적으로 흐른다.

### 2-5. 언제 멈추는가

**"다음에 물을 세 질문의 답을 내가 예측할 수 있는가?"** 예이면 인터뷰를 끝낸다.

- **신뢰도가 세 라운드 연속 오르지 않으면 인터뷰를 멈추고 그 사실을 말한다** — 그때는 질문이 모자란 것이 아니라 요청이 아직 형태를 갖추지 않은 것이라, 더 물으면 사용자가 답을 즉흥으로 만들어 낸다. 낼 것은 다음 질문이 아니라 무엇이 빠진 것 같다는 판단과 한 발 물러서자는 제안이다.

### 2-6. 의도 재진술과 확인

인터뷰가 끝나면 아래를 채워 보여주고 명시적 동의를 받는다.

```
- 결과:        <무엇이 만들어지는가>
- 사용자:      <누가 쓰는가>
- 지금 하는 이유: <왜 지금인가>
- 성공의 모습:  <끝났을 때 무엇이 참인가>
- 제약조건:    <지켜야 하는 것>
- 범위 밖:     <이번에 하지 않는 것>
```

- **"좋아 보여"·"뭐든 괜찮아"는 동의가 아니다** — 그런 답에는 재진술 중 확신이 낮은 항목 하나를 다시 묻는다.

## 계획 불필요 판정과 면제 표식

인터뷰 도중 요청이 `SKILL.md`의 「이 스킬을 건너뛰는 경우」 목록에 해당하는 것으로 좁혀지면 계획을 쓰지 않는다. 그때 `guard-write`의 plan 존재 게이트를 여는 것이 면제 표식이다.

**순서를 지킨다 — 표식은 사용자 승인 뒤에만 낸다.**

1. 무엇을 고칠 것인지 **파일 경로까지** 확정한다
2. `A) 바로 수정 / B) 계획부터`를 제시한다
3. 사용자가 A를 고르면 표식 한 줄을 출력한다 — 대상이 여럿이면 가운뎃점으로 잇는다

   ```
   [PLAN-EXEMPT] <경로> · <경로>
   ```

   경로는 플레이스홀더가 아니라 **실제 경로**를 적는다 — 훅이 그 줄에서 파일명과 부모 이름을 찾는다.
4. 같은 turn 에서 곧바로 편집한다 — 표식은 그 turn 의 도구 호출 시점에 이미 transcript 에 실려 있다

- **승인 없이 표식을 내지 않는다** — 이 게이트가 Claude 단독 판정을 통과 근거로 쓰지 않는 이유는, 값 치환에 동작 변경이 섞인 요청을 모델이 trivial 로 오판정한 실측이 있기 때문이다.
- **적은 파일만 열린다** — 훅은 표식 줄에서 파일명과 직속 부모 디렉터리 이름을 함께 본다. 작업 중 다른 파일이 필요해지면 다시 묻고 새 표식을 낸다.
- **표식을 내지 못하면 계획을 쓴다** — 사용자가 B 를 고르거나 대상이 여러 곳으로 번지면 Step 1 로 간다.
