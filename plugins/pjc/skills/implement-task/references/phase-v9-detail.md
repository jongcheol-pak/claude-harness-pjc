# Phase V-9 상세 — 시각 충실도 검증 (implement-task)

> 트리거 판정(plan `## 시각 요소 분해` 섹션 유무)과 수행 시점(V-7 이후·V-8 이전)은 SKILL.md V-9가 정본이다 — 이 파일은 수행 절차 상세만 담는다(SKILL.md 이관, v1.109.0).

1. **요소 전수 대조**: 분해 표의 각 요소·속성(**디자인 값** 기준)을 구현 결과와 하나씩 대조한다. 공유·재사용 컴포넌트도 빠짐없이 — "행만 맞추고 헤더·검색·칩은 맞겠지" 금지. **대조 결과(현재 구현 값·판정)는 이 V-9 단계에서 산출한다** — plan의 분해 표는 "디자인 값 + 확인 방법"까지만 담으므로(현재 값·일치 열은 계획 단계에 두지 않음, plan-feature Step 2.5), 여기서 각 요소의 실제 구현 값을 확인해 판정한다. (구버전 plan이 "현재 값"·"일치" 열을 이미 가진 경우엔 그 열을 갱신하며 사용해도 된다 — **열 유무와 무관하게 디자인 값 기준으로 대조**하는 것이 핵심.)

2. **각 행에 diff 위치를 지목한다 (근거 의무).** 표의 모든 행에 대해 그 디자인 값이 **어느 파일:라인에서 충족되는지** 적는다(예: `MainPage.xaml:42 CornerRadius="8"`). **지목하지 못한 행은 충족으로 보지 않는다** — "구현했다고 생각한다"는 근거가 아니다. 이 지목은 V-8 자기점검과 `spec-compliance-reviewer` 항목 I(귀속 행 대조)의 입력이 된다.

3. **빌드 ≠ 시각 일치를 명시**: 빌드 통과·테스트·코드리뷰는 **시각 충실도를 검증하지 못한다**. CSS든 XAML이든 마찬가지다 — 폰트 크기·간격·정렬·아이콘 유무·레이아웃 어긋남은 컴파일·바인딩 검사가 잡지 않는다(WinUI 3/WPF/MAUI는 XAML이 컴파일되지만 그것은 문법·바인딩 경로 검증일 뿐 화면 결과의 검증이 아니다). 따라서 빌드만으로 "디자인과 동일"을 선언하지 않는다.

4. **렌더 확인 — 3분기.** 대상과 도구 가용성으로 갈린다:

   | 상황 | 처리 |
   |---|---|
   | **웹 대상 + 렌더 캡처 도구 가용**(브라우저 자동화 MCP 등) · 로그인 불필요 | 캡처해 디자인과 **요소별로 대조**하고 결과를 표에 기록. **이 경로만 "확인됨"으로 판정할 수 있다** |
   | **데스크톱 UI 대상**(WinUI 3·WPF·MAUI 등) | 자율 루프에서 앱 기동·상태 준비·창 캡처를 신뢰성 있게 수행할 수단이 없다 → 해당 행을 **`⏳ 미확인`**으로 표기 |
   | **도구 부재 · 로그인 필요 · 캡처 환경 없음** | 위와 동일하게 **`⏳ 미확인`** 표기 |

   > 렌더 캡처 도구는 세션·설치에 따라 있을 수도 없을 수도 있다. **특정 도구의 존재를 전제하지 않는다** — 있으면 쓰고, 없으면 `⏳ 미확인` 경로로 간다.

5. **`⏳ 미확인` 행의 처리 — Phase F-8로 인계한다.** task 루프는 여기서 멈추지 않고 계속하되, **미확인 행 목록을 plan의 분해 표에 남겨 Phase F-8(시각 충실도 최종 관문)이 받도록 한다.** F-8이 완료 선언 직전에 이 목록을 확인하고, 하나라도 남아 있으면 **완료 선언을 보류하고 사용자에게 화면 확인을 요청**한다.
   - **"루프를 멈추지 않는다"가 "검증 없이 완료한다"를 뜻하지 않는다** — 인계는 검증의 이연이지 면제가 아니다. task 단계에서 세우지 않는 이유는 미확인이 task마다 반복 발생하기 때문이며, 선언 게이트는 F-8 한 곳으로 모은다.
   - 미확인 행을 완료 보고에 적는 것만으로 끝내지 않는다 — 보고에 적고 "완료"를 선언하면 사용자가 그 줄을 읽지 않는 한 그대로 묻힌다.
   - "동일하게 맞췄다"고 단정하지 않는다.

6. 분해 표에서 **❌(불일치)**가 남아 있으면 Phase I로 복귀해 수정 후 재대조한다. **`⏳ 미확인`은 ❌가 아니다**(불일치가 아니라 미검증) — Phase I 복귀 대상이 아니라 F-8 인계 대상이다.

> 핵심: "디자인과 동일하게"는 화면 전체를 요소 단위로 대조해야 하는 작업이다. 일부만 보고 "맞겠지"로 끝내면 사용자가 볼 때만 어긋남이 드러난다. 자동 확인이 불가능한 환경에서는 **확인을 생략하는 대신 완료 선언을 미룬다**(F-8).
