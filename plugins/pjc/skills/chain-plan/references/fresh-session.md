# 새 세션 권고 (`pjc:chain-plan` 착수 전)

> `../SKILL.md` 「전제조건」이 이 파일을 연다 — 이 세션에서 체인을 발동하기 전에 체인과 무관한 작업(다른 질문·편집·계획)을 했을 때만 읽는다. args 첫 블록이 `회차 경계:` 면(`pjc:plan` 이 회차를 넘김) 열지 않는다 — 그 인터뷰 맥락을 체인이 쓴다.

## 새 세션 권고

- **체인을 시작하기 전에 한 번 묻는다 — 코디네이터는 워커 메시지를 처리할 때마다 이 세션의 컨텍스트 전체를 다시 읽는다** — 무관한 작업으로 컨텍스트가 큰 채 시작하면 그 크기가 질문·보고마다 곱해진다(2026-10-04 실측: 61만 토큰 세션에서 시작한 체인이 대기 중 53턴·31M 토큰).
- **먼저 붙여넣기 프롬프트를 코드블록으로 낸다** — `/pjc:chain-plan` 다음 줄부터 사용자의 계획 목록 원문(`plan 1: … / plan 2: …`)과 이 세션에서 그 계획에 대해 이미 받은 답을 그대로 싣는다. 요약하면 새 세션이 원문 대신 이 세션의 해석으로 인터뷰한다.
- **이어 `AskUserQuestion` 으로 묻는다 — [새 세션에서 시작 (권장)] / [이 세션에서 계속]**
  - 새 세션 → 「Karina 탭에서 `/clear` 후 위 프롬프트를 붙여넣는다」를 안내하고 Run 을 만들지 않고 끝낸다. `/clear` 는 같은 탭이라 `KARINA_TAB_UUID` 가 그대로다.
  - 이 세션에서 계속 → 「전제조건」의 확인으로 간다.
