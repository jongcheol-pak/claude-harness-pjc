# 사용자에게 넘기기 (`pjc:chain-plan`)

> `../SKILL.md` 「답하는 기준」이 워커의 질문·승인 요청이나 실행 시점 승인 항목을 사용자 몫으로 넘길 때(「사용자에게 넘기기」·「미답 기본값」)와 워커 `plan.md` 승인 요청에 답할 때(「봉투 대조」·「봉투 밖 승인 요청」), 그리고 대기 출력이 `RESULT: deadline` 일 때(「미답 기본값」)만 이 파일을 연다. 무엇이 사용자 몫인지는 거기가 정본이다.

## 사용자에게 넘기기

- **사용자에게 넘길 때는 사용자를 부른 뒤 묻는다** — 알림이 없으면 사용자는 이 탭에 질문이 떠 있는 줄 모른다. 워커는 답이 올 때까지 상한 없이 기다리므로(`../../plan/references/relay-edge-cases.md`「ask 만료」) 답이 늦어도 따로 알릴 것이 없다.
  1. `PushNotification`(`status: "proactive"`, 메시지 `plan <N>: 사용자 확인 필요 — <질문 한 줄>`) — 지연 로드면 ToolSearch 로 불러 쓰고, 도구가 없거나 보내지 않았다고 하면 건너뛴다
  2. 질문 원문(승인 요청이면 그 승인 제시 전문)과 `GUESS:` 를 그대로 보이고 답을 글자 그대로 옮긴다 — 요약해 넘기면 사용자가 워커의 실제 질문이 아니라 이 세션의 해석에 답하게 된다
  3. `prior-answers.md`「앞선 답」 이 같은 질문으로 고른 앞 답이 있으면 2 에 `참고: plan <M>[ 이어받기 <k>] 에서 같은 질문에 「<답 원문>」(<사용자 답 | 코디네이터 판정>)` 을 덧붙이고, 앞 답과 어긋나게 판정해야 해 넘기는 것이면 ` — 이번에 다르게 볼 이유: <질문에 인용된 새 사실>` 을 잇는다 — 앞 답으로 대신 답하지 않는 대신 사용자가 같은 답을 빨리 고르게 하고, 출처가 없으면 사용자가 코디네이터 판정을 자기 앞 결정으로 읽는다

## 봉투 대조

- **재료는 그 승인 제시의 task 줄·`승인 필요 항목`·`DB 변경`·`실측 요지 대비:` 줄이다. 셋이 다 참이면 `Y (체인 승인 위임 — <체인 승인 때 사용자의 답 원문>)` 로 답한다** — 사용자는 체인 승인에서 이미 답했다.
  - ① task 가 그 계획의 재진술(결과·범위 밖)을 벗어나지도 빠뜨리지도 않고 — 결과의 각 항목(포함한 요청 밖 항목 포함)이 task 에 있고 spec `실측 요지:` 의 이 계획 초안 중 빠진 것은 `실측 요지 대비:` 에 근거가 있다 —, 다른 회차 task 를 흡수하지 않는다
  - ② `승인 필요 항목` 이 없거나, 체인 승인 때 명시해 승인받은 것이거나, 사용자 몫 ④ 밖의 변경(내부 API·설정 키)뿐이다
  - ③ `DB 변경` 이 체인 승인의 DB 목록 안이다(`../SKILL.md` 「답하는 기준」의 판정 불릿이 정한 새 DB 포함)
- **승인 제시 `결정:` 의 `(확인 필요)` 는 봉투 대조와 별개로 `../SKILL.md` 의 사용자 몫 넷과 판정 기준으로 가른다** — 그 표기는 워커가 답을 받지 못한 결정이라는 뜻이지 사용자 몫이라는 뜻이 아니다.

## 봉투 밖 승인 요청

- **하나라도 어긋나면 봉투 밖이다 — 회피 설계부터 지시한다.** 봉투의 task 줄 대조가 넘침이면 먼저 그 task 가 `../SKILL.md` 사용자 몫 ③ 의 지목에 드는지 본다 — 들면 넘침이 아니다(승인 제시 `요청 밖 항목:` 의 `(판정 원칙)` 표기가 그 후보다). 나머지 대조가 맞으면 `Y (코디네이터 판정 — <지목한 원칙·목표>)` 로 답한다 — 원본 이식 체인에서 원본 요소를 빼라고 하면 사용자 지시를 거스른다. 들지 않으면 그 task 없이 목표가 되는지 보고 되면 `E: <그 task 를 뺀다> (코디네이터 판정 — <근거>)`, 안 되면 사용자 몫 ③ 요청 범위 변경으로 사용자에게 넘긴다. task 줄 대조가 누락이면 `E: <빠진 항목> 을 넣거나 빠진 근거를 적는다 (코디네이터 판정 — <근거>)`. `승인 필요 항목`·`DB 변경` 대조가 어긋나면 사용자 몫(`../SKILL.md` 넷)이 아닌 한 어긋난 항목이 생기지 않는 설계가 있으면 `E: <회피 설계> (코디네이터 판정 — <근거>)`, 없을 때만 `Y (코디네이터 판정 — <근거>)` — 워커가 스스로 고른 설계가 만든 승인 항목은 대개 다른 설계로 사라진다(`../../plan/SKILL.md` Step 4). 봉투 밖이라는 사실만으로 사용자에게 넘기지 않는다.
