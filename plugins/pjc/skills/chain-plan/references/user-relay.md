# 사용자에게 넘기기 (`pjc:chain-plan`)

> `../SKILL.md` 「답하는 기준」이 워커의 질문·승인 요청이나 실행 시점 승인 항목을 사용자 몫으로 넘길 때만 이 파일을 연다. 무엇이 사용자 몫인지는 거기가 정본이다.

## 사용자에게 넘기기

- **사용자에게 넘길 때는 워커에 대기 신호를 먼저 보내고 사용자를 부른 뒤 묻는다** — 신호가 없으면 워커는 무응답과 사용자 대기를 가르지 못해 무응답 상한에서 멈추고, 알림이 없으면 사용자는 이 탭에 질문이 떠 있는 줄 모른다.
  1. `<CLI> orchestration send --to <질문 메시지의 from> --type status --subject "사용자 확인 대기 중" --body "<질문 한 줄>" 2>/dev/null`
  2. `PushNotification`(`status: "proactive"`, 메시지 `plan <N>: 사용자 확인 필요 — <질문 한 줄>`) — 지연 로드면 ToolSearch 로 불러 쓰고, 도구가 없거나 보내지 않았다고 하면 건너뛴다
  3. 질문 원문(승인 요청이면 그 승인 제시 전문)과 `GUESS:` 를 그대로 보이고 답을 글자 그대로 옮긴다 — 요약해 넘기면 사용자가 워커의 실제 질문이 아니라 이 세션의 해석에 답하게 된다
- **위임되지 않는 항목(`../SKILL.md`「체인 승인」)의 실행 승인은 봉투와 무관하게 항상 사용자에게 간다** — 그 항목들은 글로벌 규칙이 실행 시점 승인을 요구해, 체인 승인으로 미리 받을 수 없다. 워커는 그것을 `ask` 로 보낸다. 단 인증정보가 필요한 신규 외부 서비스는 워커가 `failed` 로 멈춰 보고로 온다 — 인증정보는 `ask` 본문으로 건넬 수 없다.
