# 픽스처 규약 문서

> 산문 두 축(경로·심볼)의 대상 문서다. **실물의 축소 모형이고 사본이 아니다** —
> 실물을 복사하면 71KB 가 케이스마다 복사되고, 실물이 바뀔 때마다 기대값이 흔들린다.

아래 네 줄이 **경로 후보 4건**이고 전부 이 픽스처에 실재한다. 각 줄은 후보 판정의 다른
형태를 하나씩 맡는다 — 한 줄에 몰면 어느 형태가 걸렸는지 갈리지 않는다.

- 완전 경로: `plugins/pjc/skills/sample/SKILL.md`
- 앵커 생략(접미 매치): `skills/sample/SKILL.md`
- 디렉터리: `docs/plans/`
- 글롭: `plugins/pjc/evals/*.json`

## 심볼 축

하나씩 갈라 둔다 — 한 줄에 몰면 어느 형태가 걸렸는지 갈리지 않는다.

- 루트 파일명: `setup.ps1`
- 하위 파일명: `fixture-notes.md`
