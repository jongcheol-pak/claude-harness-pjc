# 설계 원칙 (픽스처)

## 3. 만들지 않는 것 (픽스처)

### 3-1. 검증 단계를 추가하지 않는다

- **폐기한 것**: Phase V 9단계(V-1~V-9) · Phase F 8단계 · Phase G.

> **폐기 식별자(기계 대조)**: `Phase V` · `V-1`~`V-9` · `Phase F` · `Phase F-1`~`Phase F-8` · `Phase G` — 이 줄이 정본이고 「폐기 식별자 실재」 축이 파싱한다.

## 4. 문서 예산

| 대상 | 상한 | 등급 | 근거 |
|---|---|---|---|
| `SKILL.md` | **12,000 B** | **게이트** | 발동마다 전량 로드된다 |
| 단일 `references/*.md` | **15,000 B** | **게이트** | 한 번에 Read해 쓸 수 있는 크기 |
| 에이전트 정의 `agents/*.md` | **6,000 B** | **게이트** | 호출 프롬프트와 함께 로드된다 |
| 가이드 문서 (`DESIGN.md`·`AUTHORING.md`) | **13,000 B** | **통지** | 고칠 때만 열어 본다 |
| hook 스크립트 `scripts/*.ps1` | **25,000 B** | **통지** | 한 번에 Read해 고칠 수 있는 크기 |
| 근거 문서 `scripts/rules/*.md` | **20,000 B** | **통지** | 코드에서 내린 근거를 받는 그릇이다 |

**초과가 보이면 문장을 줄이지 말고 항목을 뺀다.**
